Christmas Maze: Новогодний лабиринт для манула

Интерактивная текстовая игра-лабиринт, написанная на чистом python (стандартные библиотеки) с использованием http.server

Об игре
Пользователь вводит имя и попадает в лабиринт из 15 комнат. В каждой комнате — 3 двери:
в комнатах 1–10 две двери хорошие (ведут дальше), одна плохая (отнимает подарок), в комнатах 11–15 — одна хорошая и две плохие.
Цель: пройти все 15 комнат, сохранив хотя бы один из 3 подарков.
Если подарки заканчиваются — поражение. В конце игры сохраняется результат и выводится Топ-10 игроков (файл scores.json)

Технологии
- Бэкенд: Python 3 (стандартные модули: http.server, pathlib, json, urllib, random, uuid)
- Фронтенд: HTML, CSS (без JavaScript). Шаблонизация реализована вручную через str.replace
- Данные: В памяти (games) для текущих сессий и JSON-файл (scores.json) для рейтинга

Структура проекта
- server.py — основной сервер и логика игры
- exploit_*.py — скрипты для демонстрации уязвимостей (XSS, IDOR, Path Traversal)
- patches/ — diff-файл с исправлениями (fix_*.diff)
- VULNERABILITIES.md — описание заложенных уязвимостей
- TESTING.md — таблица с результатами тестирования (до/после патчей)
- templates/ — HTML-шаблоны
- static/ — CSS-стили, анимация снежинок и картинки

Как запустить
1. Клонируйте репозиторий
2. В терминале выполните: python server.py
3. Откройте в браузере: http://localhost:8000

Безопасность
Изначально в приложении намеренно были оставлены 3 уязвимости из OWASP Top 10:
1. XSS: Вывод имени игрока без html.escape (экранирования)
2. IDOR: Доступ к игре чужого игрока по прямому идентификатору g
3. Path Traversal: Чтение файлов сервера через /static/../

В папке проекта находятся python-скрипты с эксплоитами и небольшими комментариями к ним.
В финальной версии все три уязвимости закрыты (использовано экранирование, проверка сессий через куки и валидация путей). Патчи оформлены в виде diff-файла.
